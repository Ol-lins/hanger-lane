# Hanger Lane — CIIS 332 website

Hand-coded website for **Hanger Lane**, a Tesano laundry. The public pages read as a shop site. GitHub hosting steps are in this file and in the report, not on the website.

This folder is the website. Do not open it in Dreamweaver Design View. Edit the files in a code editor.

## Pages

| File | Purpose |
| --- | --- |
| `index.html` | Home |
| `about.html` | The shop, hours, and house rules |
| `services.html` | Wash and fold, wash and iron, pickup prices |
| `packages.html` | Student, family, and shop weekly bags |
| `gallery.html` | Photographs, filters, lightbox, care video |
| `contact.html` | Booking form, shop details, map |

Shared files: `css/style.css`, `js/main.js`, `images/favicon.svg`.

## Preview on your computer

1. Open `index.html` in Chrome, Edge, or Firefox.
2. Click every menu item, including the footer links.
3. Narrow the window to check the Menu button.
4. On Gallery, use the filters and click a photo.
5. On Contact, submit an empty form, then a complete form.

## Host on GitHub Pages

1. Create a GitHub account if you do not have one.
2. Create a new public repository, for example `hanger-lane`.
3. Upload every file in this folder (keep the `css`, `js`, and `images` folders). Do not upload the `report` folder unless you want it public.
4. In the repository, open **Settings → Pages**.
5. Set Source to **Deploy from a branch**, branch **main**, folder **/ (root)**.
6. Wait a minute, then open the GitHub Pages URL.

The live site will look like:

`https://YOUR-USERNAME.github.io/hanger-lane/`
